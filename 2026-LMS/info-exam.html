Information about the exam/retake

  • The written exam will last 3 hours and will consist of problems similar to those covered in lectures and labs.
  • Any written materials (books, lecture notes, labs, etc.) are allowed during the exam. Laptops, tablets, phones, smartwatches, etc., are not allowed.
  • The exam will feature three types of problems:
    • I: a set of problems in classic format (whose correct solving requires writing out the entire solution);
    • II: a set of lab-based open-ended questions;
    • III: a set of multiple choice questions (covering both lecture and lab content).
  • The maximum score that can be obtained for solving all problems in the exam will be 12 points:
    • 4 points from Type I problems;
    • 3 points from Type II problems;
    • 4 points from Type III problems;
    • 1 default point.
  • A minimum of 5 points is required to pass the exam.

  • There will be 8 multiple-choice problems. Each problem has 5 answer options, out of which at least one and at most two are correct. The number of correct answer options (one or two) will be specified for each problem.
  • A multiple-choice problem is solved correctly if and only if ALL and ONLY the correct options are identified.
  • 0.5 points are awarded for each correctly solved multiple-choice problem.
  • If a problem has two correct answer options, partial credit will be awarded - 0.25 points/problem - if and only if a single option was checked, and the checked option is correct.
